Build races and balance transformations in-game.

DMZ Do Anything is an unofficial DragonMine Z addon for modpack creators and server administrators. Build new races, tune existing forms, and apply reviewed changes in singleplayer or on a dedicated server.

Open the editor as an administrator with /dmzdoanything.

Minecraft 1.20.1 · Forge 47.4.10 or 47.4.28

Requires DragonMine Z 2.2.1 with GeckoLib, TerraBlender, and Curios API. Use matching addon builds on the server and all clients.

Race Builder

Create a race from a template or clone an installed race. Write its description, choose starting appearance and class stats, and assign a supported racial ability. Add forms before publishing and preview each look on the rotating fighter.

Race & Form Editor

Open Saiyan from the DragonMine Z section and select Super Saiyan 2 to preview the form. Edit its supported stat multipliers, Ki upkeep, mastery, unlock requirements, TP prices, and appearance. Review and apply Base and transformation changes together.

Inside /dmzdoanything

Special Settings

Set progression and Ki rules for your world. Each restriction starts off and can be applied live.

  • Prohibit TP Gain blocks native gameplay Training Point rewards.
  • Prohibit Form Unlocking blocks native purchases, upgrades, and grants of transformation skills. Players keep what they have earned.
  • Prohibit Stat Point Spending blocks native Stats screen spending with TP or Attribute Points.
  • Prohibit Manual Ki Charging blocks charge-key recovery while passive regeneration still works.

Library and world tools

  • Addon Library groups races and transformations by source, with global search and a section for shared forms.
  • Assets lets you browse installed models, textures, skills, and abilities.
  • Delete Race hides a race from new character creation while existing characters keep their progress. Restore Race brings it back.
  • Review Changes shows staged edits and affected players before you apply them.
  • Revision History lets you restore an earlier set of world settings and edits.
